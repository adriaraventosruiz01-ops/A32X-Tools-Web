常见问题

A32X Tools 是什么？

A32X Tools 是面向 A318/A319/A320/A321 维修技术人员的专业参考应用，包含 ECAM 复位程序、跳开关位置照片、A320neo 电子设备舱照片导览、结构损伤报告、电气触点、Alpha Callups 和常用件号。

如何查找 A320 ECAM 信息的复位程序？

在应用中搜索 ECAM 信息名称（例如 ELEC TR 1(2) FAULT），即可看到分步复位程序、需要操作的跳开关及其面板位置照片，并可使用内置计时器。也可以按 ATA 章节浏览。

能找到跳开关在飞机上的位置吗？

可以。每个复位所需的跳开关都标明了所在面板，并配有真实的面板照片，方便在驾驶舱或电子设备舱中快速找到。

没有网络也能用吗？

可以。所有数据都内置在应用中，在机坪、机库或飞机上没有信号也能正常使用。

应用界面是中文的吗？

应用界面和数据为英文，与 AMM、MEL、ECAM 等官方维修资料使用的语言保持一致，方便与手册对照。App Store 中的应用介绍提供中文。

如何获取？是订阅制吗？

一次性购买，没有订阅，也没有应用内购买。iPhone 用户可在中国区 App Store 下载。Google Play 在中国大陆不可用。

可以代替 AMM 吗？

不能。A32X Tools 仅供培训和参考使用，执行任何维修或运行工作前都必须查阅最新的空客官方手册。
